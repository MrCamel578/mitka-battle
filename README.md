# МитькаBattle — обновление интерфейса и игровых механик

В проекте:
- обновлённый адаптивный интерфейс;
- визуальные изображения скинов из каталога Steam Community;
- синтезированные звуковые эффекты с переключателем;
- блокировка скина сохраняется на сервере и исключает его из «Продать всё», апгрейда и контрактов;
- контракты принимают 3–10 незаблокированных предметов и всегда возвращают предмет из каталога; диапазон цены цели обычно 0.85–2.2x от суммы входных предметов, если в каталоге есть подходящие варианты;
- аккаунты, баланс и игровые операции остаются на API с PostgreSQL.

## Обновление на Render через GitHub

1. Распакуйте архив и замените в своём GitHub-репозитории `server.js`, `package.json`, `render.yaml` и папку `public/` этими файлами. Не удаляйте существующий `catalog.json` в корне, если он используется скриптами проверки; файл `public/catalog.json` нужен фронтенду.
2. Проверьте `DATABASE_URL` в Render → ваш Web Service → Environment. Не добавляйте строку базы или `SESSION_SECRET` в GitHub.
3. В Render должны быть заданы `SESSION_SECRET` (не менее 32 символов), `DATABASE_URL`, `ADMIN_USERNAME` и `ADMIN_PASSWORD`. Не храните пароль администратора в репозитории.
4. Закоммитьте и отправьте изменения в GitHub (`git add .`, `git commit -m "Update contracts inventory locks sounds"`, `git push`). Если Render связан с этим репозиторием и включён Auto-Deploy, деплой начнётся автоматически. Иначе откройте Render → Manual Deploy → Deploy latest commit.
5. Дождитесь статуса `Live`, затем обновите сайт с очисткой кэша (`Ctrl+Shift+R`). Проверьте вход, открытие кейса, блокировку скина, продажу всех незаблокированных предметов, апгрейд и контракт.

## Важно

- Перед заменой сделайте коммит или копию текущего репозитория, чтобы можно было откатиться.
- Новые проверки блокировки выполняются на сервере, а не только в интерфейсе.
- Контракты — игровая механика симулятора. Цена в каталоге не является реальной стоимостью Steam и не гарантирует прибыль.
- `render.yaml` не содержит секретов; добавляйте их в Environment в Render.
