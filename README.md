# Митька-Battle — бесплатное размещение с Supabase

Проект использует Node.js/Express и PostgreSQL в Supabase для хранения аккаунтов, паролей в виде bcrypt-хешей, профиля игрока и сессий. Файлы сайта находятся в `public/`.

## Важно о ключах

- Не публикуйте пароль базы данных или Supabase secret key в GitHub и не отправляйте их в чат.
- Для сервера используется `DATABASE_URL` из Supabase → Project Settings → Database → Connection string → URI. Это не `Publishable key` и не `Secret key`.
- `SESSION_SECRET` должен быть длинной случайной строкой. Render создаст её автоматически из `render.yaml`.

## Настройка локально

1. Установите Node.js 20 или новее.
2. Создайте `.env` на основе `.env.example` и задайте `DATABASE_URL` и `SESSION_SECRET`.
3. Выполните `npm install`, затем `npm start`.

## Размещение на Render

1. Загрузите эти файлы в GitHub, заменив старые `server.js`, `package.json`, `.env.example`, `render.yaml` и `README.md`. Папку `public/` оставьте без изменений.
2. В Render создайте/откройте Web Service из репозитория. Можно выбрать Blueprint, если Render предлагает прочитать `render.yaml`.
3. В Environment добавьте `DATABASE_URL` (Supabase URI connection string). Не добавляйте Publishable key вместо него.
4. Убедитесь, что `SESSION_SECRET` задан и `NODE_ENV=production`.
5. Запустите deploy и проверьте URL `/api/me` — он должен вернуть JSON с `user: null` для неавторизованного посетителя.

## Бесплатный тариф и ограничения

Render Free может засыпать после простоя; первый запуск после простоя будет медленным. Бесплатный тариф Supabase имеет лимиты и проект может приостанавливаться после длительного бездействия в зависимости от текущих условий тарифа. Проверьте актуальные лимиты в панелях сервисов.

## Ограничение игровой логики

Этот проект сохраняет профиль, присланный браузером. Это не является защитой от читов: игрок может попытаться изменить баланс/инвентарь через инструменты разработчика. Для публичной экономики нужно переносить открытие кейсов, апгрейды и изменение баланса на сервер с транзакциями и проверкой результатов.
